# The Fitting Room (unlisted)

Weekly spoken version of the fashion digest, narrated by the
`weekly-fashion-podcast` scheduled task from the Notion "Weekly Fashion
Digest" archive. The repo is public only because free GitHub Pages needs
that; the name is random and the page carries noindex. Treat the feed URL as
a secret.

This repo holds data only: `show.json`, `episodes.json`, `feed.xml`, covers
and audio. The task publishes with the shared kit (`podcast-kit`):
`~/.local/share/threshold-and-bar/bin/publish_episode.py` adds an episode.
